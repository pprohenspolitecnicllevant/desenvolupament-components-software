# Electrical Grid Stability Simulated Data

`xarxa_electrica.csv` és una còpia sense canvis de `Data_for_UCI_named.csv`, del conjunt
*Electrical Grid Stability Simulated Data*, de Vadim Arzamasov, publicat al UCI Machine
Learning Repository. Només s'ha canviat el nom del fitxer.

> Arzamasov, V. (2018). Electrical Grid Stability Simulated Data [Dataset]. UCI Machine
> Learning Repository. https://doi.org/10.24432/C5PG66

Llicència: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Són **dades simulades**: cada fila és l'anàlisi d'estabilitat d'una xarxa en estrella de quatre
nodes (un productor al centre i tres consumidors) que fa servir el control descentralitzat
*Decentral Smart Grid Control*. No són mesures d'una xarxa real.

Les imatges de roba de la part D són de Fashion-MNIST (Zalando Research, llicència MIT) i es
carreguen de la còpia de `UT06-Xarxes_convolucionals/fashion_mnist/`, que té la seva pròpia
atribució.

La figura `corbes_learning_rate.png` la genera `make_figura.py`.
